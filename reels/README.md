# 주도주 릴스

국내 주도주 타임라인 하루를 1080×1920 세로 영상(mp4, 30fps, 약 23초)으로 굽는다. 해외는 조회수가 나오지 않아 접었다(2026-10).

```bash
cd reels
npm install                          # 처음 한 번 — playwright, ffmpeg, 글꼴
npx playwright install chromium      # 처음 한 번

node render.mjs 2026-09-23           # → out/2026-09-23/주도주-국내-0923-v7.mp4 (최신 버전)
node render.mjs 2026-09-23 --point "문장"  # 첫 화면 핵심 포인트를 직접 쓴다
node render.mjs 2026-09-23 --v 1     # → out/2026-09-23/주도주-국내-0923-v1.mp4 (예전 버전으로)
node render.mjs 2026-09-23 --secs 8  # 앞 8초만 — 화면 확인용
node render.mjs 2026-09-23 --fps 60  # 60fps → out/2026-09-23/주도주-국내-0923-v7-60fps.mp4 (굽는 시간 두 배)
```

- 데이터는 운영 타임라인 API(`/api/leader-timeline`)에서 받는다
- 한 편에 수 분 걸린다. 화면 녹화가 아니라 가짜 시계로 한 프레임씩 넘기며 찍어서, 원본 크기 그대로이고 프레임이 빠지지 않는다
- 소리는 없다. 음악은 올릴 때 붙인다
- 영상은 `out/<날짜>/`에 남는다(git에서 뺐다). 폴더가 있으면 거기에 더한다
- 영상 옆에 본문(`…-v7.txt`)도 남는다. 위는 그대로 붙여 넣을 본문, 아래는 올리기 전에 확인할 근거(키워드·기사)
  - 사유는 운영 "왜 오르나" API에서 받는다. **API가 지금 것만 주므로 장 마감 뒤 그날 안에 구워야** 맞는 사유가 붙는다
  - 근거 기사 제목·링크는 로그인해야 실린다 — 브라우저에서 judozoo.com의 `judozoo_session` 쿠키 값을 복사해
    `JUDOZOO_SESSION=… node render.mjs 2026-09-23`처럼 넣는다. 없으면 건수만 적힌다
  - v1은 본문을 만들지 않는다

## 버전

화면은 버전마다 `reel.vN.html` 한 벌씩이다. `--v`를 빼면 번호가 가장 큰 버전으로 굽는다.
화면을 크게 바꿀 땐 기존 파일을 고치지 말고 `reel.v(N+1).html`로 복사해서 고친다 — 예전 버전도 언제든 다시 구울 수 있게.
v1~v3에는 해외 화면 코드가 남아 있지만 `render.mjs`가 국내만 넘기므로 쓰이지 않는다.
버전끼리 지키는 약속은 `render.mjs`와의 접점뿐이다 — `window.__REEL__`로 데이터를 받고, `__play()`로 재생하고, `__REEL_SECONDS`로 길이를 알린다.

| 버전 | 내용 |
|---|---|
| v1 | 약 41초. 여는 장면 4.6초(1위 바통), 본 장면 30초(하루 흐름 + 굵직한 자막), 닫는 장면 5초(마감 순위 · 주소). 국내는 20:00까지 |
| v2 | 약 19초. 여는 장면 없이 훅으로 시작, 가변 속도, 두 시장 모두 정규장 마감까지 — 아래 "화면" |
| v3 | v2와 같은 구성에 낮과 밤 — 국내는 밝은 화면(낮), 해외는 v2 그대로 어두운 화면(밤) |
| v4 | v3에서 훅·폭발·"역전!"·"마감 1위는 누구일까?"를 뺐다. 첫 1위가 선 때부터 시작하고, 자막은 1위에 오른 종목의 이름과 그때 등락률뿐 — 첫 1위부터 바뀔 때마다 큰 숫자로 터진다 |
| v5 | v4와 같은 구성에 어두운 화면 — v2의 밤 색으로 되돌렸다 |
| v6 | 결말(마감 순위 + 핵심 포인트)부터 보여 주고 되감아 시작한다. 1위 자막에 "출발 1위"와 AI 근거를 단다. 끝은 다시 결말로 돌아와 첫 프레임과 이어진다 |
| v7 | v6에서 1위를 거쳐 갈 종목의 이름을 가렸다가 역전할 때 드러낸다 |

## 화면 (v7)

어두운 화면 하나다(v2의 밤 색). 색은 CSS 변수(`:root`)와 캔버스 테마(`TH`) 두 곳에 있다.

직접 열면 데이터가 없어 빈 화면이다 — `render.mjs`가 `window.__REEL__`에 데이터를 넣고 `__play()`를 부른다.

| 구간 | 내용 |
|---|---|
| 결말 2.8초 | 정규장 마감 순위 1~5위. 0.35초에 핵심 포인트("핵심 포인트" / 종목명 등락률 / AI 근거)가 출발 1위처럼 번쩍이고 흔들리며 등락률이 치솟는다 |
| 되감기 1.6초 | 15:29에서 첫 1위가 선 때로 차트와 시계가 거꾸로 달린다 |
| 본 장면 16.5초 | "출발 1위"가 터지며 시작한다. 가변 속도 — 1위가 바뀌는 곳은 느리게(본 장면 11.1초일 때의 속도), 남는 시간은 잔잔한 구간이 나눠 갖는다. 1위가 바뀌면 종목명·등락률·AI 근거가 터진다. 1위를 거쳐 갈 종목은 그때까지 이름이 블러로 가려져 있다(출발 1위는 빼고). 첫 화면 결말(순위·핵심 포인트)에서도 같은 종목 이름을 가리고, 끝에서 돌아온 결말엔 다 드러나 있다 |
| 다시 결말 1.7초 | 15:29에 잠깐 멈췄다가 차트가 흐려지고 마감 순위가 차오른다. 마지막 프레임이 첫 프레임과 같아 반복 재생이 이어지고, 핵심 포인트가 다시 터진다 |

핵심 포인트는 ① `--point`로 준 문장 ② 마감 1위부터 내려가며 AI 근거가 있는 첫 종목의 근거 순으로 고르고, 둘 다 없으면 비운다(순위만 나온다).
AI 근거는 운영 "왜 오르나" API에서 받는다. API가 지금 것만 주므로 **그 날짜에 만들어진 근거만** 쓴다 — 지난 날을 구우면 근거 없이 나온다. 근거가 없는 1위 자막은 종목명과 등락률만 뜬다.

궁금증을 부르는 멘트("마감 1위는 누구일까?" 같은)는 쓰지 않는다 — 선이 움직이는 화면이 재미를 낸다.
1위는 10분 넘게 이어진 구간만 친다. 바뀐 횟수가 넷을 넘으면 오래 지킨 넷만.

구간 — **정규장 마감까지**. 08:00~15:29(15:30~15:40은 타임라인이 찍지 않는 쉬는 구간).
정규장이 끝나면 순위가 거의 움직이지 않고, 사람들이 "오늘 장"이라 느끼는 것도 정규장이다.
캘린더·홈의 "마감 주도주"는 NXT 애프터(20:00) 기준이라 날에 따라 영상의 정규장 마감 1위와 다를 수 있다 — 영상엔 "정규장 마감 주도주 순위"라고 적는다.
