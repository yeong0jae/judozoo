# 주도주 릴스

주도주 타임라인 하루를 1080×1920 세로 영상(mp4, 30fps, 약 19초)으로 굽는다.

```bash
cd reels
npm install                          # 처음 한 번 — playwright, ffmpeg, 글꼴
npx playwright install chromium      # 처음 한 번

node render.mjs us 2026-09-25        # → out/주도주-해외-0925-v3.mp4 (최신 버전)
node render.mjs kr 2026-09-23        # → out/주도주-국내-0923-v3.mp4
node render.mjs kr 2026-09-23 --v 1  # → out/주도주-국내-0923-v1.mp4 (예전 버전으로)
node render.mjs kr 2026-09-23 --secs 8   # 앞 8초만 — 화면 확인용
node render.mjs us 2026-09-28 --fps 60   # 60fps → out/주도주-해외-0928-v3-60fps.mp4 (굽는 시간 두 배)
```

- 데이터는 운영 타임라인 API(`/api/leader-timeline`)에서 받는다. 날짜는 각 시장의 현지 날짜 — 해외는 뉴욕 날짜
- 한 편에 수 분 걸린다. 화면 녹화가 아니라 가짜 시계로 한 프레임씩 넘기며 찍어서, 원본 크기 그대로이고 프레임이 빠지지 않는다
- 소리는 없다. 음악은 올릴 때 붙인다
- 영상은 `out/`에 남는다(git에서 뺐다)
- 영상 옆에 본문(`…-v2.txt`)도 남는다. 위는 그대로 붙여 넣을 본문, 아래는 올리기 전에 확인할 근거(키워드·기사)
  - 사유는 운영 "왜 오르나" API에서 받는다. **API가 지금 것만 주므로 장 마감 뒤 그날 안에 구워야** 맞는 사유가 붙는다
  - 근거 기사 제목·링크는 로그인해야 실린다 — 브라우저에서 judozoo.com의 `judozoo_session` 쿠키 값을 복사해
    `JUDOZOO_SESSION=… node render.mjs us 2026-09-28`처럼 넣는다. 없으면 건수만 적힌다
  - v1은 본문을 만들지 않는다

## 버전

화면은 버전마다 `reel.vN.html` 한 벌씩이다. `--v`를 빼면 번호가 가장 큰 버전으로 굽는다.
화면을 크게 바꿀 땐 기존 파일을 고치지 말고 `reel.v(N+1).html`로 복사해서 고친다 — 예전 버전도 언제든 다시 구울 수 있게.
버전끼리 지키는 약속은 `render.mjs`와의 접점뿐이다 — `window.__REEL__`로 데이터를 받고, `__play()`로 재생하고, `__REEL_SECONDS`로 길이를 알린다.

| 버전 | 내용 |
|---|---|
| v1 | 약 41초. 여는 장면 4.6초(1위 바통), 본 장면 30초(하루 흐름 + 굵직한 자막), 닫는 장면 5초(마감 순위 · 주소). 국내는 20:00까지 |
| v2 | 약 19초. 여는 장면 없이 훅으로 시작, 가변 속도, 두 시장 모두 정규장 마감까지 — 아래 "화면" |
| v3 | v2와 같은 구성에 낮과 밤 — 국내는 밝은 화면(낮), 해외는 v2 그대로 어두운 화면(밤) |

## 화면 (v2 · v3)

v3는 v2와 구성이 같고 색만 시장을 따른다. 한국 시간으로 국장은 낮에, 미장은 밤에 열리니 국내는 밝게, 해외는 어둡게 —
피드에서 첫 프레임만 봐도 어느 시장인지 갈린다. 색은 CSS 변수(`body.day`)와 캔버스 테마(`THEMES`) 두 곳에 있다.
낮의 종목 색은 밝은 바탕에서 묻히지 않게 명도를 내린 별도 10색이고, 선·점 번짐은 줄였다.

직접 열면 데이터가 없어 빈 화면이다 — `render.mjs`가 `window.__REEL__`에 데이터를 넣고 `__play()`를 부른다.

| 구간 | 내용 |
|---|---|
| 첫 프레임 | 여는 장면 없이 선 다섯 개가 이미 움직이는 화면. 훅은 종목 이름 없이 숫자만 — "개장 1분 만에 +272%?" |
| 본 장면 14.5초 | 가변 속도 — 순위가 움직이는 곳은 느리게, 멈춘 곳은 빠르게. 폭발 순간엔 큰 숫자가 치솟고, 1위가 바뀌면 "역전!"과 함께 번쩍인다. 끝에 "마감 1위는 누구일까?" |
| 닫는 장면 3.6초 | 정규장 마감 1위를 크게, 1위를 거쳐 간 종목, 주소 |
| 마지막 0.5초 | 첫 화면으로 돌아간다 — 반복 재생의 이음새 |

폭발(10분 사이 등락률이 15%p 넘게 뛴 순간), 1위 교체, 훅 문구, 시작 시각은 모두 그날 데이터에서 정해진다.
폭발은 그날의 주인공 것만 쓴다 — 2위 안에 30분 넘게 머문 종목 중 가장 오래 머문 종목. 4~5위를 잠깐 스친 급등주는 아무리 크게 뛰어도 뽑지 않는다.
정규장 열고 한 시간 안의 폭발이면 "개장 N분 만에", 아니면 "N시 N분, 갑자기". 폭발이 없는 날은 "오늘 1위만 N 번 바뀜".

구간 — 두 시장 모두 **정규장 마감까지**. 국내 08:00~15:29(15:30~15:40은 타임라인이 찍지 않는 쉬는 구간), 해외 04:00~16:00(뉴욕).
정규장이 끝나면 순위가 거의 움직이지 않고, 사람들이 "오늘 장"이라 느끼는 것도 정규장이다.
국내 캘린더·홈의 "마감 주도주"는 NXT 애프터(20:00) 기준이라 날에 따라 영상의 정규장 마감 1위와 다를 수 있다 — 영상엔 "정규장 마감 주도주 순위"라고 적는다.
