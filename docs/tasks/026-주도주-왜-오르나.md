# 026 — 주도주 "왜 오르나"

Goal: 국내·해외 주도주 5종목마다 **오른 이유 한 줄**과 키워드 칩, 근거·관련 기사를 붙인다. 사용자가 종목을
하나씩 열어 뉴스를 찾아 읽지 않아도, 홈 카드와 주도주 목록에서 "왜"가 바로 보이게 한다.

> **판단 보조이지 추천이 아니다.** PRD 범위 밖에 "투자 자문·종목 추천"이 있다. 사유는 기사에 나온 사실을
> 요약할 뿐이고, 권유 표현은 프롬프트와 후처리 양쪽에서 막는다.

아키텍처: https://claude.ai/artifact/ART836npB8B62DoE56nGmS (비공개. v6 기준)

## 진입 조건 (2026-09-28 확인)

### 무엇이 주도주인지는 이미 정해져 있다

- 국내 `LeadingStocks.leaders`, 해외 `OverseasStockRanks.leaders` — 오른 종목 가운데 거래대금·등락률 백분위의
  가중 기하평균 상위 5개(`library.ranking.top_balanced`). 이 문서는 그 5종목에 사유를 붙이기만 한다.
- 풀은 10초마다 갈아 끼워진다(025 §진입 조건). 사유 작업은 캐시에 있는 풀을 **읽기만** 한다.

### LLM은 Vertex AI의 Gemini

- VM 서비스 계정이 이미 `cloud-platform` 스코프다. `roles/aiplatform.user` 하나만 더하면 ADC로 부를 수 있다 — **API 키 없음**
- 사유의 재료는 Gemini의 **Google 검색 그라운딩**이다. KIS 뉴스는 제목뿐이라 쓰지 않는다
- 종목 상세(`StockDetailPanel`)에는 뉴스 목록이 없다 — 새 카드와 겹칠 것이 없다

### 가격 (Vertex AI 가격표, 2026-09-28 확인)

| 항목 | 단가 |

| Gemini 3.8 Flash 입력 | 100만 토큰당 $0.75 (2027-01-01부터 $1.50) — Global 엔드포인트. 리전 고정은 10% 더 |
| 출력 (응답 + 사고) | 100만 토큰당 $3.75 (2027-01-01부터 $7.50) |

## 설계 결정

| 항목 | 선택 | 이유 |
|---|---|---|
| 대상 | 국내·해외 주도주 5종목 | 한 번 주도주에 들어온 종목은 빠져도 그날 사유가 남는다. 후보 목록에 보이면 사유도 같이 보인다 |
| 언제 만드나 | ① 새로 들어온 종목은 생성 시간 안이면 **다음 분에 바로**. ② **정해진 시각**마다 그 시각의 주도주 5종목을 다시 | KIS 뉴스 변화를 신호로 쓰지 않는다 — 품질이 낮고 해외는 수집 범위가 좁다 |
| 중복 방지 | 최근 30분 안에 만든 종목은 ②에서 건너뛴다 | 09:28 진입 → 09:29 생성 → 09:30 또 생성을 막는다 |
| 국내 생성 시간 | **08:30~20:00** KST. 정해진 시각 08:30 · 09:30 · 11:00 · 14:00 · 16:00 · 18:00 · 20:00 | 장 초반 30분은 뉴스도 없고 종목도 날뛴다 |
| 해외 생성 시간 | **23:00~07:00** KST(서머타임 중). 정해진 시각 23:00 · 01:00 · 03:00 · 05:30 · 07:00 | 모두 **뉴욕 기준**(10:00 · 12:00 · 14:00 · 16:30 · 18:00) — 겨울에는 KST로 한 시간씩 늦다 |
| 초기화 | 국내 08:00, 해외 뉴욕 04:00(프리마켓 시작) | 전날 사유가 오늘 종목 옆에 붙지 않게. 해외는 초기화부터 첫 생성까지 비어 있다(KST 17:00~23:00) |
| 휴장일 | 초기화도 생성도 없다 | 직전 거래일 사유가 다음 거래일 초기화까지 남는다 |
| 기사 범위 | 직전 거래일 장 마감 이후(국내 전날 15:30, 해외 뉴욕 16:00 이후) | 그보다 오래된 기사는 오늘 사유로 보기 어렵다 |
| 실패 | 3분 뒤 **한 번만** 다시. 그래도 실패하면 이전 사유 유지 | 첫 생성이 실패하면 다음 정해진 시각까지 비기 때문 |
| 설명 없음 | 저장하되 **목록에 안 보인다.** 상세에는 관련 기사만. 이미 설명된 사유가 있으면 덮지 않는다 | 검색 결과가 매번 조금씩 달라, 멀쩡하던 사유가 사라지는 걸 막는다 |
| 이력 | **생성할 때마다 한 행.** 화면은 최신 사유만 | 이력은 테이블 자체. 카운터·상태 열을 따로 두지 않는다 |
| 모델 | Gemini 3.8 Flash, Global 엔드포인트, 사고 수준 낮게 | 사유 한 줄 작업이라 충분. 출력 토큰(사고 포함)이 비용의 대부분 |
| 기능 위치 | 새 feature `insight` | 국내·해외 두 feature의 application을 부른다(024·025와 같은 이유) |
| 조회 API | `GET /api/insight/reasons?market=kr|us` — 지금 세션의 사유 전체 | 주도주 응답에 끼워 넣지 않는다. 주도주가 insight에 의존하지 않고, 갱신 주기도 다르다(10초 vs 분) |
| 로그인 | 키워드·사유 문장·기준 시각은 **공개**, 근거·관련 기사는 **로그인** | 한 줄은 가입 유도, 근거는 로그인 뒤 |
| 일일 상한 | 하루 전체 150회(설정값) | 넘으면 그날 생성을 멈춘다. 이 상한이면 최악도 월 약 $50 |

### 화면 (시안 v7에서 확정)

**목록 — 홈 국내·해외 카드, 주도주 목록(국내·해외)**

- 종목명 아래 한 줄: `[키워드] [키워드] 사유 문장`. 넘치면 문장을 말줄임
- 설명 없음 종목은 칩도 문장도 붙이지 않는다
- "AI 요약" 표시는 목록에 붙이지 않는다

**키워드 칩**

- 최대 2개, 칩 하나 8자 안팎
- 그날 사유의 핵심 단어 — 회사명·제품명·계약 상대 같은 고유명사와 사건을 우선한다
- "상승", "호재", "기대", "강세" 같은 일반어는 쓰지 않는다
- 여러 종목을 묶는 분류(테마)가 아니다 — 정규화하지 않는다

**상세 카드 — 주도주 목록 오른쪽 패널, 기존 종목 상세 위**

```
LG이노텍 011070                               +7.48%
왜 오르나 [AI 요약]                        10:41 기준
[Aeva] [라이다] 美 라이다 업체 Aeva 지분가치 상승

근거 기사   (최대 2건, 제목 → 원문 새 탭)
관련 기사   (최대 2건, 제목 → 원문 새 탭)
```

- 시각은 **사유 갱신 시각만**. 기사 시각은 넣지 않는다. 해외도 KST로 적는다
- 관련 기사 = 사유와 부딪히는 기사("특별한 호재 없이"), 수급 기사. **시세 중계 기사**("주가, 9월 28일 장중 … 상승")는 넣지 않는다
- 설명 없음 → 사유 문장·근거 없이 관련 기사만. 관련 기사도 없으면 카드를 띄우지 않는다
- 방문자 → 칩·사유 문장까지 보이고, 기사 자리는 "근거·관련 기사 n건은 로그인 후 볼 수 있습니다"
- 기존 종목 상세(주도주 조건·분봉·일봉·수급)는 이 카드 아래에 그대로. 방문자에게는 지금처럼 로그인 안내

## 알려진 함정

- **검색 결과는 매번 다르다** — 같은 종목도 다시 만들면 설명 없음이 나올 수 있다. 표시할 행 고르기가 이걸 막는다
- **시세 중계 기사가 많다** — 걸러내지 않으면 근거·관련 칸이 "주가 … 상승" 기사로 찬다
- **해외 거래일** — 뉴욕 거래일로 저장한다. KST 자정을 넘는다(025와 같다)
- **해외 시각은 뉴욕 기준, 표시는 KST** — 스케줄은 뉴욕 시간대로 걸고, 화면의 "기준" 시각만 KST로 바꾼다

## 후속

- 타임라인 "들어옴" 순간에 사유 한 줄(025 §후속)
- 설명 없음 급등 종목 모아 보기 — 저장은 이미 하고 있다
