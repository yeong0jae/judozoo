# 027 — 모의 종가베팅

Goal: 지수·수급 아래 새 탭 **종가베팅**. 가입자가 하루 한 종목을 가상 금액으로 종가에 사고, 다음 날 아침
5분 중간가로 판다. 결과로 하루 랭킹을 매긴다. 종베 판단에 쓰는 지표(시장·종목 수급, 고가 마감, 신고가)를
등급 하나로 묶어 보여 주고, 다음 날 결과로 그 등급이 맞았는지 복기하게 한다.

> **가상 금액으로 하는 게임이다.** 실제 주문이 나가지 않고, 돈을 걸거나 받지 않고, 경품도 없다.
> 등급은 판단 보조이지 추천이 아니다(PRD 범위 밖 "투자 자문·종목 추천"). 화면 맨 아래에 그렇게 적는다.

시안: https://claude.ai/artifact/7fGCK3sTF1cfYBxTMkimck (비공개. **v6 시간대별** 기준, 다섯 순간을 나란히 펼친 보드 포함)
로컬 화면: `frontend/src/pages/ClosingBetPage.tsx` — 값은 `components/closingbet/mock.ts` 예시. `?moment=review|bet|night|result|holiday`로 시각을 덮어쓴다

## 진입 조건 (2026-10-02 확인)

### 이미 있는 것

- **주도주·후보 목록** — `leadingstock` 후보 풀(10초 갱신, 08:00~20:00). 베팅 대상은 이 목록 안에서만
- **시장 수급 구간** — `market.investor_sessions`가 프리·오전·오후·**마감(15:00~15:40)**·**애프터(15:40~20:00)** 다섯 구간을
  통합(KRX+NXT) 기준으로 나눠 준다. 선물은 `futures_investor_sessions`, 5일은 `investor_daily_history`·`futures_investor_daily_history`
- **야간선물** — `market.application`의 야간선물 시세(18:00~익일 06:00)
- **NXT 프리·애프터 분봉** — 키움 SOR 통합 코드(`_AL`)라야 08:00~ 봉과 20:00까지 봉이 온다(`platform/kiwoom/market.py`)
- **종목 투자자별 매매** — `platform/kiwoom/investor.py`(SOR 통합). 일별이라 5일 합은 여기서 낸다
- **거래일 달력** — `market.calendar`. 휴장일에는 판이 서지 않는다
- **가입자** — `auth.AppUser`(대체 키 `id`). 닉네임은 여기에 없다

### 없는 것

- 사용자별 데이터 — 017에서 이슈 메모·관심 테마를 기능째 지웠다. **이 기능이 다시 들인다**(PRD §사용자·§기능 요구사항 개정 필요)
- 일봉 기준 **52주 신고가·박스 돌파** 판정 — 지금 "돌파"는 최근 3거래일 분봉의 전고점(spec §5.4)이라 뜻이 다르다
- 종목별 **NXT 상장 여부** — 매도 창(08:00 / 09:00)을 가르는 값

### 종베 체크 다섯 가지 → 등급

| 체크 | 맞는 조건 | 데이터 |
|---|---|---|
| 고가 마감 | 현재가(체결가)가 당일 고가 대비 **−1.5% 이내** | 시세 |
| 외국인 | 당일 순매수 > 0 (통합). 5일 합은 설명에만 | 종목 투자자별 |
| 기관 | 당일 순매수 > 0 (통합). 5일 합은 설명에만 | 종목 투자자별 |
| 시장 막판 | 그 종목 **시장**의 마감 + 애프터 구간 외인 + 기관 합 > 0 | `investor_sessions` |
| 신고가 | **52주 신고가** 또는 **박스 돌파**(종가가 직전 **60거래일 고가**를 넘음). 둘 다면 신고가로 표시 | 일봉(새로 판정) |

- 등급 — 다섯 개 S · 넷 A · 셋 B · 둘 이하 C (금·은·동·철)
- "돈 몰림"(거래대금 순위)은 뺐다 — 주도주·후보는 이미 몰린 종목이다
- 베팅 중 등급은 **실시간**, 복기는 **20:00 스냅샷** 그대로

## 알려진 함정

- **10초 풀** — 베팅한 종목이 몇 초 뒤 목록에서 빠질 수 있다. 베팅은 그 순간 목록으로 검증하고, 이후엔 건드리지 않는다
- **KRX 기본 코드는 정규장에서 멈춘다** — 통합(`_AL`)이 아니면 20:00 종가도, 08:00 봉도 안 온다
- **ka10051 전일 값** — 08:00 전에는 시장 투자자 값이 전일 것을 오늘로 줄 수 있다(`market.application` `_DAILY_FLOW_START`). 스냅샷은 20:00이라 괜찮지만, 정산 쪽에서 아침 수급을 쓰지 않는다
- **시간외 단일가** — 비NXT 종목은 15:30 종가 뒤 16:00~18:00 단일가가 있어도 매수가는 KRX 종가다
- **결과 발표 중 내 종목** — 비NXT 종목을 산 사람은 08:05에 다른 사람 결과만 보인다. 09:05까지 가려 두는 게 맞다
