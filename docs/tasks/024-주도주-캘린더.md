# 024 — 주도주 캘린더

Goal: 홈 주도주 카드가 매일 고른 종목을 **날짜별로 남기고**, 한 달을 달력 한 장으로 되돌아본다.
국내와 해외를 한 칸에 겹쳐 "직전 해외장 → 당일 국내장" 흐름이 보이게 한다.

> **새 기준을 만드는 작업이 아니다.** 무엇이 주도주인지는 홈 카드가 이미 정한다
> (`LeadingStocks.leaders`, `OverseasStockRanks.leaders`). 이 문서는 그 답을 **마감 때 한 번 저장**하고
> 보여줄 뿐이다. 기준을 바꾸면 캘린더도 그날부터 따라 바뀐다.

시안: https://claude.ai/artifact/HpuTfC9Ekvb5gShMsxLZMz (예시 데이터, 비공개)

## 진입 조건 (2026-09-26 확인)

### 홈 주도주는 어디에도 남지 않는다

| | 국내 | 해외 |
|---|---|---|
| 풀 | 키움 거래대금 상위 50 (`ka10032`, KRX+NXT 통합, 관리종목 제외) | KIS 거래대금 순위 (`HHDFS76320010`) 나스닥·뉴욕·아멕스 합산 상위 40 |
| 거르기 | ETF·스팩 제외, 거래대금 35위 이내, **오른 종목만** | ETF 제외, **오른 종목만** |
| 세우기 | 거래대금·등락률 백분위 기하평균, 거래대금 가중 0.65 | 같은 방식, 가중 0.55 |
| 개수 | **최대 5 — 0~5개** | **최대 5 — 0~5개** |
| 세션 끝 | 20:00 KST (NXT 애프터마켓 포함) | 16:00 ET (프리마켓~정규장. 애프터마켓 없음) |
| 저장 | **없음** — 요청마다 풀에서 계산 | **없음** |

오른 종목이 적은 날은 1~2개, 없으면 0개다. 캘린더는 **"주도주 없음"과 "기록 없음"을 구분해야** 한다.

### 풀은 세션이 끝나면 멈춘다

두 풀 모두 세션 밖에서는 다음 세션 시작(국내 08:00 KST, 해외 04:00 ET)까지 캐시를 들고 있는다
(`_pool_ttl`). **마감 뒤 첫 요청이 받은 풀이 밤새 홈에 뜬다.** 스냅샷을 그 뒤에 찍으면 홈과 같은 값이 된다.

### 순위 API는 날짜를 받지 않는다

`ka10032`·`HHDFS76320010` 둘 다 "지금" 순위만 준다. 과거는 순위 API로 다시 받을 수 없다 — §6 참고.

## 설계 결정

| 항목 | 선택 | 이유 |
|---|---|---|
| 무엇을 저장하나 | 홈 카드의 `leaders(5)` 결과 그대로 — 순번·종목·가격·등락률·거래대금 | 캘린더는 "그날 홈이 뭐라고 했나"를 답한다. 다시 계산하지 않는다 |
| 국내 스냅샷 시각 | **20:01 KST**, 평일, 국내 휴장일 제외 | NXT 애프터마켓까지 끝난 뒤. 홈이 멈춘 값과 같다 |
| 해외 스냅샷 시각 | **16:01 America/New_York**, 평일, 미국 휴장일 제외 | 홈 해외 세션이 16:00에 끝난다. **KST로 걸지 않는다** — 05:01 고정이면 서머타임 해제(11월) 뒤 정규장 중에 찍힌다 |
| 애프터마켓 (해외) | 반영하지 않는다 | 홈이 16:00에 멈추고, 미국의 하루 등락률도 정규장 종가 기준이다. 애프터마켓 변동은 다음 날 몫 |
| 저장 날짜 | 각 시장의 **현지 거래일** — 국내는 KST, 해외는 뉴욕 날짜 | 짝짓기는 화면이 한다. 저장을 화면 규칙에 묶지 않는다 |
| 0개인 날 | **날 행은 남기고 종목 행만 없다** | 날 행이 없으면 "안 찍혔다"와 구분이 안 된다 |
| 테이블 | `leader_day`(시장·거래일·찍은 시각, **(시장, 거래일) 유니크**) + `leader_day_stock`(날 id·순번·종목) | 0개인 날을 표현하려면 날이 따로 있어야 한다. FK는 걸지 않는다 — 코드베이스 관례 (V007 주석) |
| 다시 찍기 | 같은 (시장, 거래일)이 있으면 **덮어쓴다** | 재기동·수동 재실행이 중복을 만들지 않게. 유니크가 최후 방어선 |
| 기능 위치 | 새 feature `leadercalendar` | 국내·해외 두 feature의 `application`을 부른다 — 교차 호출은 application 사이에서만 (architecture.md) |
| 짝짓기 | **화면이 한다.** 국내 날짜 D 칸에 D 직전 평일의 해외장 | "직전 해외장 → 당일 국내장". 월요일 칸은 금요일 해외장 |
| 조회 API | `GET /api/leader-calendar?month=2026-09` — 국내 날들, 해외 날들을 따로 | 9/1 칸은 해외 8/31이 필요하다. **해외는 요청 달의 직전 평일부터** 내려준다 |
| 로그인 | 공개 | 홈 주도주가 이미 공개다. 같은 정보를 모아 보여줄 뿐이다 |
| 테마 | 넣지 않는다 | 백엔드에 테마 데이터가 없다 |

### 문구 (시안에서 확정)

| 보기 | 설명 |
|---|---|
| 함께 | 직전 해외장과 당일 국내장 마감 기준 주도주 |
| 국내 | 당일 국내장 마감 기준 주도주 |
| 해외 | 직전 해외장 마감 기준 주도주 |

칸 안 라벨은 `해외 · 9/22(화)`, `국내`. "간밤 미국"이라고 쓰지 않는다.

## 6. 9월 채우기 (한 번 돌리고 끝)

순위 API가 과거를 안 주므로 **종목별 일봉으로 그날 풀을 다시 만든다.** 결과는 "당시 홈에 떴던 것"이 아니라
"지금 규칙을 그날에 적용했으면 뽑혔을 것"이다. 가중치가 0.45 → 0.7 → 0.65로 바뀌어 와서 어차피 당시 값과 같을 수 없다.

- [ ] 범위: 국내 9/1~9/23 거래일 17일(9/24·25 추석 휴장). 해외 8/31~9/25 뉴욕 거래일(9/7 노동절 휴장). 스냅샷 시작 전날까지
- [ ] **먼저 확인** — 국내 일봉(`ka10081`), 해외 일봉(`HHDFS76240000`) 응답에 거래대금 필드가 있는가.
      지금 두 파서 모두 안 읽는다. 없으면 종가 × 거래량으로 어림한다
- [ ] 국내: `stocks` 전 종목 일봉 → 날짜별 거래대금 순위 → 35위 이내 · ETF/스팩 제외 · 오른 종목 → 0.65 점수로 5개
- [ ] 해외: `overseas_stocks` 전 종목 일봉 → 날짜별 3거래소 합산 순위 상위 40(ETF 포함 순위) → ETF 제외 · 오른 종목 → 0.55 점수로 5개
- [ ] 등락률은 앞날 종가로 계산 (첫날 8/31·9/1 앞날도 같은 페이지 안에 있다)
- [ ] 일봉 한 번에 100일치 이상이 와서 **종목당 한 번**이면 된다. 호출 제한만 지킨다
- [ ] 스크립트는 `backend/scripts/`에 두고 **서비스 코드에 넣지 않는다.** 점수 함수는 도메인 것을 그대로 부른다
- [ ] 화면에서는 실제 스냅샷과 **같은 모양** — 따로 표시하지 않는다
- [ ] 결과 몇 날을 기억과 대조한다

### 재구성이 실제와 다른 점 (받아들인 것)

- 국내 — 일봉은 KRX만. **NXT 거래대금이 빠진다**
- 국내 — 관리종목 여부는 지금 기준
- 해외 — 홈 풀은 프리마켓 포함 세션, 일봉은 정규장
- 해외 — 그사이 마스터에서 빠진 종목(상폐·심볼 변경)은 안 잡힌다

## 검증

- [ ] 스냅샷 첫날 국내: 20:01 행의 종목·순서가 그 시각 홈 카드와 같은가
- [ ] 스냅샷 첫날 해외: **16:01 ET에 KIS 순위가 이미 정규장 종가를 반영하는가.**
      저장된 가격을 다음 날 일봉 종가와 대조한다. 종가 동시호가가 늦게 들어오거나 애프터마켓 값으로
      바뀌어 오면 시각을 옮긴다
- [ ] 서머타임 해제 주(11월 첫째 일요일 뒤) 해외 작업이 06:01 KST에 도는가
- [ ] 국내 휴장일·미국 휴장일에 행이 안 생기는가
- [ ] 두 인스턴스가 같은 DB를 보면 스냅샷이 두 번 돈다 — 유니크 + 덮어쓰기로 결과가 하나인가

## 알려진 함정

- **해외 작업의 날짜** — 16:01 ET는 KST로 다음 날이다. 서버 기본 시간대(`now()`가 KST)로 거래일을 잡으면 하루 밀린다
- **실패를 0개로 저장하지 않는다** — 브로커 오류가 "주도주 없음"으로 영구히 남는다
- **`seo.json`** — 경로를 더하고 안 적으면 빌드가 선다 (022)
- **마이그레이션 먼저, 배포 나중** — 반대면 스케줄러가 없는 테이블에 쓰다 실패한다

- 9월 이전 채우기 — 필요해지면 §6 스크립트를 범위만 넓혀 다시 돌린다
