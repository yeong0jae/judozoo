# 024 — 주도주 캘린더

Goal: 홈 주도주 카드가 매일 고른 종목을 **날짜별로 남기고**, 한 달을 달력 한 장으로 되돌아본다.
국내와 해외를 한 칸에 겹쳐 "직전 해외장 → 당일 국내장" 흐름이 보이게 한다.

> **새 기준을 만드는 작업이 아니다.** 무엇이 주도주인지는 홈 카드가 이미 정한다
> (`LeadingStocks.leaders`, `OverseasStockRanks.leaders`). 이 문서는 그 답을 **마감 때 한 번 저장**하고
> 보여줄 뿐이다. 기준을 바꾸면 캘린더도 그날부터 따라 바뀐다.

시안: https://claude.ai/artifact/HpuTfC9Ekvb5gShMsxLZMz (예시 데이터, 비공개)

## 진입 조건 (2026-09-26 확인)

### 홈 주도주는 어디에도 남지 않는다

| | 국내 | 해외 |
|---|---|---|
| 풀 | 키움 거래대금 상위 50 (`ka10032`, KRX+NXT 통합, 관리종목 제외) | KIS 거래대금 순위 (`HHDFS76320010`) 나스닥·뉴욕·아멕스 합산 상위 40 |
| 거르기 | ETF·스팩 제외, 거래대금 35위 이내, **오른 종목만** | ETF 제외, **오른 종목만** |
| 세우기 | 거래대금·등락률 백분위 기하평균, 거래대금 가중 0.65 | 같은 방식, 가중 0.55 |
| 개수 | **최대 5 — 0~5개** | **최대 5 — 0~5개** |
| 세션 끝 | 20:00 KST (NXT 애프터마켓 포함) | 16:00 ET (프리마켓~정규장. 애프터마켓 없음) |
| 저장 | **없음** — 요청마다 풀에서 계산 | **없음** |

오른 종목이 적은 날은 1~2개, 없으면 0개다. 캘린더는 **"주도주 없음"과 "기록 없음"을 구분해야** 한다.

### 풀은 세션이 끝나면 멈춘다

두 풀 모두 세션 밖에서는 다음 세션 시작(국내 08:00 KST, 해외 04:00 ET)까지 캐시를 들고 있는다
(`_pool_ttl`). **마감 뒤 첫 요청이 받은 풀이 밤새 홈에 뜬다.** 스냅샷을 그 뒤에 찍으면 홈과 같은 값이 된다.

### 순위 API는 날짜를 받지 않는다

`ka10032`·`HHDFS76320010` 둘 다 "지금" 순위만 준다. 토스 랭킹 API(`/api/v1/rankings`)도 `duration`이 "지금부터 거꾸로"의
기간(1d·1w…)이라 특정 날짜를 고를 수 없다. 과거는 순위 API로 다시 받을 수 없다 — §6 참고.

## 설계 결정

| 항목 | 선택 | 이유 |
|---|---|---|
| 무엇을 저장하나 | 홈 카드의 `leaders(5)` 결과 그대로 — 순번·종목·가격·등락률·거래대금 | 캘린더는 "그날 홈이 뭐라고 했나"를 답한다. 다시 계산하지 않는다 |
| 국내 스냅샷 시각 | **20:01 KST**, 평일 | NXT 애프터마켓까지 끝난 뒤. 홈이 멈춘 값과 같다 |
| 해외 스냅샷 시각 | **16:01 America/New_York**, 평일 | 홈 해외 세션이 16:00에 끝난다. **KST로 걸지 않는다** — 05:01 고정이면 서머타임 해제(11월) 뒤 정규장 중에 찍힌다 |
| 애프터마켓 (해외) | 반영하지 않는다 | 홈이 16:00에 멈추고, 미국의 하루 등락률도 정규장 종가 기준이다. 애프터마켓 변동은 다음 날 몫 |
| 저장 날짜 | 각 시장의 **현지 거래일** — 국내는 KST, 해외는 뉴욕 날짜 | 짝짓기는 화면이 한다. 저장을 화면 규칙에 묶지 않는다 |
| 날의 세 상태 | 날 행 없음 = **기록 없음** / 날 행 + 종목 없음 = **주도주 없음** / 날 행 + `closed` = **휴장** | 셋이 화면에서 다르게 보여야 한다. 종목 테이블 하나로는 갈리지 않는다 |
| 휴장일 | 스냅샷 작업이 **건너뛰지 않고 휴장으로 남긴다** (`calendar.is_holiday`) | 조회 때마다 휴장 API를 부르지 않는다. 해외는 날짜마다 토스를 불러야 해 무겁다. 이름(추석 등)은 판정 API가 주지 않아 "휴장"으로만 적는다 |
| 테이블 | `leader_day`(시장·거래일·찍은 시각·`closed`, **(시장, 거래일) 유니크**) + `leader_day_stock`(날 id·순번·종목) | FK는 걸지 않는다 — 코드베이스 관례 (V007 주석) |
| 테이블 생성 | 기동 때 `create(checkfirst=True)` — `AppUser`·`Feedback`과 같은 방식 | 새 테이블은 배포만으로 생긴다. **열 추가는 이 방식으로 안 된다** — `closed`는 V008로 수동 적용했다 |
| 다시 찍기 | 같은 (시장, 거래일)이 있으면 **덮어쓴다** | 재기동·수동 재실행·두 인스턴스가 한 벌만 남긴다. 유니크가 최후 방어선 |
| 기능 위치 | 새 feature `leadercalendar` | 국내·해외 두 feature의 `application`을 부른다 — 교차 호출은 application 사이에서만 (architecture.md) |
| 개수 상수 | `leadercalendar.application.LEADERS_COUNT = 5`를 **따로 적었다** | 홈의 `LEADERS_COUNT`는 presentation에 있다. application이 presentation을 가져다 쓰지 않는다 |
| 짝짓기 | **화면이 한다.** 국내 날짜 D 칸에 D 직전 평일의 해외장 | "직전 해외장 → 당일 국내장". 월요일 칸은 금요일 해외장. 백엔드 `previous_weekday`와 같은 규칙 |
| 조회 API | `GET /api/leader-calendar?month=2026-09` — 국내 날들, 해외 날들을 따로 | 9/1 칸은 해외 8/31이 필요하다. **해외는 요청 달의 직전 평일부터** 내려준다 |
| 로그인 | 공개 | 홈 주도주가 이미 공개다. 같은 정보를 모아 보여줄 뿐이다 |
| 테마 | 넣지 않는다 | 백엔드에 테마 데이터가 없다 |
| 과거 날짜 | **채우지 않는다** (§6) | 재구성은 가능하지만 전 종목 일봉 1.7만 건이라 두 시간 넘게 걸린다 |

칸 안 라벨은 `해외 · 9/22(화)`, `국내`. "간밤 미국"이라고 쓰지 않는다. 오른쪽 상세의 국내 제목은 "국내"뿐 —
"점수 순"을 붙이지 않는다.

### 디자인 — 시안 치수를 px로 그대로

달력과 오른쪽 패널은 **시안 CSS의 px 값을 그대로** 쓴다(칸 최소 높이 132px, 칸 여백 10·12px, 해외 띠 6·8px,
패널 16px, 본문 14px, 줄 높이 `normal`). 페이지 제목·보기 전환·달 이동은 다른 페이지처럼 rem이다.

한 번 rem으로 바꿨다가 되돌렸다. 이 앱은 루트 글자 크기가 화면 폭을 따라 20px까지 커져서(`index.css`의 `clamp`),
rem이면 넓은 화면에서 칸·글자가 시안보다 1.25배 커지고 성겨 보인다. 크기를 안 적은 글자는 루트 20px을 물려받아
오른쪽 패널 종목명이 특히 커졌다. 앱 줄 높이 1.5도 행 간격을 벌렸다.

해외 띠는 연보라(`--leader-overseas` `#6d5bd0` / 다크 `#a597f0`, 면 `--leader-overseas-tint`). 휴장 칸은 빗금(`.leader-closed`).

## 6. 과거 날짜 — 채우지 않기로 했다

순위 API가 과거를 안 주므로 **종목별 일봉으로 그날 풀을 다시 만드는** 길밖에 없다. 결과는 "당시 홈에 떴던 것"이 아니라
"지금 규칙을 그날에 적용했으면 뽑혔을 것"이다.

확인한 것 (2026-09-26, 운영 컨테이너에서 조회):

- 키움 일봉(`ka10081`)에 거래대금 `trde_prica`가 있다 — **백만 원** 단위. 등락률은 `pred_pre`로 계산
- KIS 해외 일봉(`HHDFS76240000`)에 거래대금 `tamt`(**달러**)와 등락률 `rate`가 있다
- 일봉 한 번에 100일치 이상이 와서 종목당 한 번이면 된다

스크립트를 짜서 확인 모드로 돌렸다가 **중단했다.** 대상이 국내 4,403 · 해외 12,829종목이라, 서버와 리미터를 나누지 않는
별도 프로세스로 초당 2건씩 부르면 두 시간 넘게 걸린다. 스크립트는 커밋을 되돌렸다 — 다시 필요하면 위 사실로 새로 짠다.

대신 **장이 닫혀 풀이 멈춰 있는 동안** 마지막 장을 그대로 찍었다 (2026-09-26 토, 수동):

- [x] 국내 9/23 — 홈 풀이 9/23 마감값인지 삼성전자 등락률(+3.62%)을 일봉과 대조해 확인
- [x] 해외 9/25(뉴욕)
- [x] 휴장 — 국내 9/24·25(추석), 미국 9/7(노동절)

### 다시 채운다면 재구성이 실제와 다른 점

- 국내 — 일봉은 KRX만. **NXT 거래대금이 빠진다**
- 국내 — 관리종목 여부는 지금 기준
- 해외 — 홈 풀은 프리마켓 포함 세션, 일봉은 정규장
- 해외 — 그사이 마스터에서 빠진 종목(상폐·심볼 변경)은 안 잡힌다
- **토큰** — 로컬에서 운영 앱키로 부르면 새 토큰을 발급해 운영 토큰을 죽일 수 있다(키움은 앱키당 하루 1개).
  운영 컨테이너 안에서 DB에 남은 토큰으로 돌린다

## 알려진 함정

- **해외 작업의 날짜** — 16:01 ET는 KST로 다음 날이다. 서버 기본 시간대(`now()`가 KST)로 거래일을 잡으면 하루 밀린다
- **실패를 0개로 저장하지 않는다** — 브로커 오류가 "주도주 없음"으로 영구히 남는다
- **휴장 판정이 실패하면 주말만 휴장으로 본다** — 평일 휴장일에 토스 조회가 실패하면 휴장 대신 전날 풀이
  그날 주도주로 남는다. 드물다. 생기면 그날 행만 `record_closed`로 고친다
- **열 추가는 수동이다** — 기동 생성은 새 테이블만 만든다. `leader_day`에 열을 더하려면 SQL을 먼저 적용하고 배포한다
- **`seo.json`** — 경로를 더하고 안 적으면 빌드가 선다 (022)
- **치수를 rem으로 바꾸지 않는다** — §설계 결정 — 디자인
