# 025 — 주도주 타임라인

Goal: 홈 주도주 카드가 고르는 5종목을 **1분마다 남겨**, 하루 동안 주도주가 어떻게 바뀌어 갔는지를 한 화면에서
되돌려 보고, 장중에는 지금 흐름을 따라 본다. 레일 메뉴 "주도주"와 "캘린더" 사이에 "타임라인" 탭으로 넣는다.

> **새 기준을 만드는 작업이 아니다.** 무엇이 주도주인지는 홈 카드가 정한다(`LeadingStocks.leaders`,
> `OverseasStockRanks.leaders`). 024 캘린더가 그 답을 **하루 한 번** 남긴다면, 이 문서는 **1분마다** 남긴다.

시안: https://claude.ai/artifact/UNurbgD5tu4n9pWYdX7sYY (예시 데이터, 비공개. v30 기준)

## 진입 조건 (2026-09-27 확인)

### 풀은 이미 10초마다 갈아 끼워지고 있다

| | 국내 | 해외 |
|---|---|---|
| 풀 갱신 | `leadingstock.scheduler` 10초 (`_POOL_REFRESH_SECONDS`) | `overseasleadingstock.scheduler` 10초 |
| 캐시 수명 | 장중 15초 (`_POOL_TTL_SECONDS`) | 장중 15초 |
| 세션 | 08:00~20:00 KST (`market_status`) | 04:00~20:00 뉴욕 (`us_market_status`) — 2026-09-27 애프터마켓까지 늘림 |
| 개수 | 최대 5 — 0~5개 | 최대 5 — 0~5개 |

1분 스냅샷은 **캐시에 있는 풀을 읽기만** 한다. 브로커 호출은 늘지 않는다.

### 1분 데이터는 흔들린다

시안의 예시 데이터로 재 보니 5위 경계에서 두 종목이 1분마다 자리를 바꾸는 흔들림이 많다. 원본 그대로 세면
하루 "들고 나고 바뀐 횟수"가 114번, **3분 넘게 이어진 변화만** 세면 26번이었다. 화면의 줄 순서·배지·순위 변동은
다듬은 값을, 띠(타임라인)는 원본을 쓴다 — §설계 결정.

## 설계 결정

| 항목 | 선택 | 이유 |
|---|---|---|
| 간격 | **1분** | 5분·3분과 나란히 비교했다. 1분이 짧게 들렀다 나간 종목까지 잡는다. 흔들림은 화면이 다듬는다 |
| 찍는 시간 | 국내 08:00~19:59 KST, 해외 04:00~20:00 뉴욕(마감 분 포함) | 홈 풀이 도는 세션과 같다 |
| 쉬는 구간 | 국내 08:50~09:00, 15:30~15:40은 **찍지 않는다** | 단일가·장 전환 구간이라 순위가 멈춰 있거나 뜻이 흐리다. 화면은 빗금으로 둔다 |
| 휴장일 | 작업을 돌리지 않는다 | 달력에서 그날로 오면 "휴장" 빈 화면 |
| 무엇을 남기나 | 그 1분의 `leaders(5)` 그대로 — 순번·종목·가격·등락률·누적 거래대금 | 캘린더와 같다. 다시 계산하지 않는다 |
| 0개인 분 | **분 행은 남기고 종목 행만 없다** | 분 행이 없으면 "안 찍혔다"와 "주도주 없음"이 갈리지 않는다 — 024와 같은 이유 |
| 테이블 | `leader_tick`(시장·거래일·현지 시각, **(시장, 시각) 유니크**) + `leader_tick_stock`(틱 id·순번·종목) | 024 `leader_day`와 같은 모양. FK 없음 |
| 다시 찍기 | 같은 (시장, 시각)이 있으면 덮어쓴다 | 재기동·두 인스턴스 |
| 실패 | 풀 조회가 실패하면 **그 분은 남기지 않는다** | 0개로 남기면 "주도주 없음"으로 거짓말한다. 화면에는 빈 분(띠가 끊김)으로 보인다 |
| 기능 위치 | 새 feature `leadertimeline` | 캘린더와 같은 이유 — 국내·해외 두 feature의 application을 부른다 |
| 다듬기(3분)는 어디서 | **화면** | 원본을 그대로 내려주고 화면이 다듬는다. 기준(3분)을 바꿔도 저장된 데이터는 그대로 |
| 조회 API | `GET /api/leader-timeline?market=kr&date=2026-09-23` — 그날 전체. 장중에는 `&since=10:59`로 그 뒤만 | 하루 전체는 약 700분 × 5종목. 장중에 1분마다 전체를 다시 받지 않는다 |
| 응답 모양 | 종목 사전 한 번 + 분마다 `[시각, [종목 번호…], [등락률…], [거래대금…]]` | 같은 종목 이름·코드를 700번 싣지 않는다 |
| 로그인 | 공개 | 홈 주도주·캘린더가 공개다 |
| 보관 기간 | **결정 필요** (§결정 필요) | 하루 약 7천 행(국내·해외 합쳐 틱 1.4천 + 종목 7천) |

### 화면 (시안 v30에서 확정)

**배치**

- 머리줄: 제목 "주도주 타임라인" · 장중이면 파란 점 + "47초 전"(오늘의 주도주 `PageHeader`와 같은 모양) ·
  국내/해외 · 날짜 이동
- 타임라인 카드: 머리줄(선택 시각 · 장 구분 · 재생 속도 0.5×/1×/2× · ■ 정지 · ▶ 재생) + 왼쪽 종목 칸 + 오른쪽 띠
- 오른쪽: 순위 변동(들어옴 · 빠짐 · 1위 교체 · 주도주 없음)
- 시안에 있던 요약 타일 4개, 스냅샷 카드, 부제목·하단 설명 문구는 **없앴다**

**시간축**

- 국내는 08~20시. 해외는 **한국 시간**(17~05시, 서머타임이면 +13시간)으로 그리고, 머리줄에 "뉴욕 15:59"를 곁에 적는다
- 세션 띠: 국내 프리 / 정규장 09:00–15:30 / 애프터 15:40–20:00, 해외 프리 17:00–22:30 / 정규장 22:30–05:00 / 애프터 05:00–09:00
- 장중이면 지금 뒤는 빗금 + 가운데 "장 진행 중"

**왼쪽 종목 칸** (한 줄)

- 순위 배지(선택 시각) · 종목명 · ▲▼/"새로" · 등락률 · 거래대금 · 머문 시간·최고 순위
- 위 **5칸 고정** — "{시각} 주도주 순위"(최신이면 "마감 주도주 순위"/"지금 주도주 순위"). 주도주가 모자라면
  남는 칸은 "비어 있음", 0개면 1위 자리에 "주도주 없음 · 주도주에 오른 종목이 없어요". 개수는 소제목에 적지 않는다
- 아래 "주도주였던 종목" — **선택 시각까지 주도주였다가 빠진 종목만, 가장 최근에 빠진 순**. 아직 등장하지 않은 종목은 숨긴다

**움직임**

- 줄 순서는 **선택 시각의 순위**. 재생·클릭·← →·"최신으로"·**마우스로 훑을 때** 모두 줄이 위아래로 미끄러진다(0.45초)
- 줄 순서·배지·들고 남은 **3분 넘게 이어진 5종목 순서**를 따른다. 띠는 1분 원본
- 처음 등장하는 종목은 아래에서 떠올라 올라온다
- 움직임 줄이기 설정이면 미끄러짐 없이 바로 바뀐다

**색**

- 순위 = 파랑 한 색 5단계(1위가 가장 밝다). 다크 바탕에서 서열 램프 검증 통과. 4·5위 배지는 흰 숫자
- "새로"·들어옴 = **민트** `#5eead4` (앱에서 다른 뜻으로 쓰지 않는 색. 빨강·파랑=등락, 주황·하늘=반등·꺾임, 보라=승격·AI는 피했다)
- 치수는 캘린더처럼 **px 고정**(024 §디자인과 같은 이유)

**재생**

- 1× = 하루(약 12시간)를 30초. 0.5×·2×. 재생 중 속도를 바꾸면 그 자리에서 이어 간다
- ■ = 멈추고 맨 처음 시각으로, ▶/❚❚ = 그 자리에서 멈춤·이어 가기

## 해외 애프터마켓 (2026-09-27)

실적 발표가 대개 정규장 마감 직후(한국 새벽 5시 무렵)라 큰 움직임이 애프터마켓에 나온다. 해외 세션을
뉴욕 04:00~20:00으로 늘렸다 — 홈 해외 카드·헤더 세션·타임라인이 함께 애프터마켓까지 돈다.
캘린더는 그대로 정규장 마감(16:01)을 남긴다(트레이딩뷰도 일봉·기본 등락률은 정규장만 쓴다).

- 데이마켓(뉴욕 20:00~04:00)은 넣지 않는다 — 체결이 대체거래소(블루오션)라 KIS의 NAS/NYS/AMS 거래대금 순위에 없다.
  KIS는 주간거래를 `BAQ`/`BAY`/`BAA` 같은 별도 거래소 코드로 다루는 것으로 안다(순위 API가 받는지는 미확인)
- 해외 타임라인은 961칸(04:00~20:00)이다 — 칸 수를 시장별(`MarketSpec.slots`)로 나눴다
