# tasks 아카이브

Phase별 태스크 체크리스트. **개발 이력 기록이며 현재 시스템의 명세가 아니다.**

`tasks-000` ~ `tasks-013`은 **자동 매매 시스템 시절**의 작업 기록이다. 이후 프로젝트가 매매 판단 보조 시스템으로 전환하면서 해당 코드(매매 사이클 / 주문 / 체결 / 실적 / STOMP)는 전부 제거됐다. 전환 경위는 [`../plan.md`](../plan.md)을 참고한다.

이 문서들을 읽을 때 유의할 점:

- 여기 적힌 API·엔티티·화면은 **대부분 지금 존재하지 않는다**
- 현재 시스템의 정의는 [`../prd.md`](../prd.md) / [`../spec.md`](../spec.md)에 있다
- 배포 인프라(`tasks-013`)와 leadingstock 테스트(`tasks-014`)는 현재까지 유효하다
