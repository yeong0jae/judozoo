# PRD: 주도주 자동 트레이딩 시스템

## 개요

사용자가 주도주를 선정하여 시스템에 명령하면, 시스템이 정해진 기준에 따라 자동으로 매매하고 결과를 리포트로 제공하는 자동 트레이딩 시스템.

---

## 플로우

```
사용자: 주도주 선정 → 종목명 + 1회 매수 금액 입력
     ↓
시스템: 사전 정의된 기준에 따라 자동 매매 실행
     ↓
결과: 매매 결과 리포트 출력
```

---

## 거래 환경

- **실거래 전용** — 실제 증권사 계좌, 실제 자금으로 운용
- 모의투자 / 백테스트 모드는 본 PRD 범위에 포함하지 않음
- 시스템 배포 전 **모든 매매 룰의 단위 테스트 / 통합 테스트로 검증 필수** (실거래에서 룰 버그는 즉시 손실로 직결)
- **시스템 다운/재시작**: 진행 중인 명령 자동 복구 없음. 재시작 시 사용자가 현재 포지션을 직접 확인 후 수동 처리

### 증권사 연동

- **한국투자증권 KIS Developers** API 사용
- **REST API**: 주문 (매수/매도), 잔고/체결 조회, 시세 조회
- **WebSocket**: 실시간 시세 및 체결 통보 수신. 끊김 시 자동 재연결 시도 + 재연결 완료 전까지 REST 폴링으로 시세 감지 유지
- **인증**: OAuth2 (AppKey + AppSecret으로 액세스 토큰 발급, 만료 시 재발급)
- 추후 결정 사항:
  - 인증 키 보관 방식 (환경변수 / DB 암호화 / 시크릿 저장소)
  - 실시간 시세 데이터 소스 (WebSocket 구독 vs REST 폴링)

## 매매 명령

### 취소 처리

- 매수 진행 중 취소 시 — 추가 매수 즉시 중단 + 보유 수량 **시장가 전량 매도** 후 명령 종료
- 취소는 매매 사이클 전체를 종료 (익절/손절 룰 이어가지 않음)
- 매도 실패 시 5초 간격 무제한 재시도 (체결 완료까지)
- **in-flight 매수 주문이 있을 때 취소**: KIS API로 해당 주문 취소 시도 → 취소 성공 시 잔여 보유 수량만 매도, 취소 실패(이미 체결) 시 체결 수량 포함 전량 매도

### 중복 명령 처리

- 진행 중인 종목에 새 명령이 들어오면 **거부** (에러 메시지 표시)
- 기존 명령이 완전 청산(익절/손절/본전 매도/장마감 강제 청산)된 후에만 같은 종목 재명령 가능
- 한 종목 = 한 매매 사이클 원칙
- **다중 종목 동시 운용**: 종목 수 제한 없음. 잔고가 허용하는 만큼 동시 명령 가능

### 명령 가능 시간

- **거래일 확인**: 앱 시작 시 KIS API 영업일 조회로 당일 거래 가능 여부 확인. 휴장일이면 명령 접수 전체 차단
- 정규장 시간 내(09:00 ~ 15:30) 명령 가능
- 단, **신규 명령 컷오프 시각** = `15:20 - (추가 매수 간격 × 2)`
  - 기본 3분 간격: **15:14까지** 명령 가능
  - 5분 간격: **15:10까지** 명령 가능
- 컷오프 이후 신규 명령은 거부 (UI에서 에러 메시지)
- 이유: 3회 매수가 강제 청산 시각(15:20) 전에 안정적으로 완료되도록 보장

### 입력값

| 항목 | 설명 | 기본값 | 허용 범위 |
|------|------|--------|----------|
| 종목명 | 매수할 종목 (검색 지원) | - | - |
| 1회 매수 금액 | 회당 매수 금액 (원 단위) | - | 10,000원 이상, 현재가 기준 1주 가격 이상 |
| 추가 매수 간격 | 1회 매수 후 추가 매수 대기 시간 (분) | 3분 | 1분 ~ 30분 |
| 분할 매도 비율 | 목표 익절 시 1회당 매도 비율 | 20% | 10% ~ 30% |
| 중도 익절 기준 수익률 | 매수 미완료 시 익절 전환 수익률 | 3% | 0.1% ~ 10% |
| 본전 매도 기준 수익률 | 본전 매도 발동 전 최소 상승 수익률 | 2% | 0.1% ~ 10% |
| 손절 기준 손실률 | 손절 발동 손실률 | -2% | -0.1% ~ -10% |

> **1회 매수 금액 검증**: 명령 접수 시 KIS API로 현재가를 조회하여 1주 가격보다 낮으면 즉시 거부 (에러 메시지 표시)

> **잔고 검증**: 명령 접수 시 `1회 매수 금액 × 3`을 충당할 잔고가 있는지 확인. 이미 진행 중인 다른 종목 명령의 예약 금액도 차감하여 계산. 잔고 부족 시 즉시 거부 (에러 메시지 표시)

## 시스템 매매 규칙

### 1. 매수

- 명령 수신 즉시 1회 매수
- 이후 **사용자 설정 간격**(기본 3분)으로 2회 추가 매수 (총 3회)
- **주문 유형: 시장가** (모든 매수 회차)
- **부분 체결 / 미체결 처리**: 회차별로 시장가 주문 후 부분 체결분은 보유하고 미체결 잔량만 즉시 취소.
  다음 회차는 예정된 시각에 새 시장가 주문으로 정상 진행 (잔량 누적·재시도 없음).
  → 총 매수액이 의도(1회 매수 금액 × 3)보다 적을 수 있으나, 익절/손절은 비율 기반이므로 정상 동작.

### 2. 목표 익절

**3회 매수 시도가 완료된 후** 발동 (체결 여부와 무관하게 3회 주문 시도를 완료한 시점 기준). 총 매수 수량을 **사용자 설정 비율**(기본 1/5)로 분할 매도:

| 조건 | 매도 수량 |
|------|----------|
| 수익률 +2% 도달 | 총 수량의 N% (설정값) |
| 수익률 +3% 도달 | 총 수량의 N% |
| 수익률 +5% 도달 | 총 수량의 N% |
| 나머지 수량 | 추세 꺾임 OR 상한가 도달 — **둘 중 먼저 발생한 이벤트** 시점에 전량 시장가 매도 |

> **매도 수량 계산**: 소수점 이하 절사, 나머지는 마지막 매도에 포함

> **갭상승 / 급등으로 복수 단계 동시 충족 시**: 충족된 모든 단계를 한 번에 발동하여 합산 비율로 매도.
> 예) 시초가가 +6%로 시작하면 2%/3%/5% 단계가 모두 충족 → 분할 비율 20% × 3단계 = **60% 즉시 매도**

**예시 (기본값 20%, 총 100주 매수 시)**
- 2% 수익 → 20주 매도
- 3% 수익 → 20주 매도
- 5% 수익 → 20주 매도
- 잔여 40주 → 추세 꺾임 또는 상한가 시 전량 매도

### 3. 중도 익절

3회 매수 완료 전, **수익률 +N% 이상**(기본 3%, = 중도 익절 기준 수익률) 달성 시:
- 추가 매수 중단
- **그 시점까지 보유한 수량**을 기준으로 목표 익절 규칙에 따라 분할 매도
- +N% 미만에서는 익절 발동하지 않고 정상적으로 추가 매수 진행
  (즉, +2% 단계 매도는 3회 매수 완료 후에만 발동)

### 4. 본전 매도

3회 매수 시도 완료 후, 매수가 대비 **+N% 이상 상승**(기본 2%) 후 **현재가 ≤ 매수가** 도달 시:
- 보유 수량 전량 **시장가 매도**

> **"매수가" 정의**: 가중평균 매수가(매수 시 수수료/세금 포함). 산식은 [매수가 산정](#매수가-산정-증권사-기준) 참고.
> 매도 시 발생하는 수수료/세금은 본전가에 반영하지 않음 → 실제로는 매도 비용만큼 소폭 손실 발생.

### 5. 손절

3회 매수 완료 또는 매수 진행 중, 매수가 대비 **-N% 하락**(기본 -2%) 시:
- 추가 매수 없이 전량 **시장가 매도**

> **익절/손절 동시 충족 시**: 손절 우선 발동. 손절 = 전량 청산이므로 이후 모든 시그널 자동 소멸.

### 6. 장 마감 강제 청산

- 정규장 마감 직전 (**15:20**, 마지막 동시호가 진입 전)에 보유 수량 전량 **시장가 매도**
- 익절/손절/본전 매도 어느 것도 발동하지 않은 채 보유 중인 모든 포지션이 대상
- 매수가 진행 중이라면 추가 매수도 함께 중단
- 모든 명령은 **당일 청산** 원칙 — 다음 날로 이월하지 않음

### 7. 시장 안전장치(VI / 거래정지 / 호가공백) 처리

시스템은 VI, 거래정지, 상한가 호가공백 등을 별도로 감지하지 않고, **주문 결과(성공/실패)만 보고 동작**한다.

- **매수 회차 주문 실패 시**: 해당 회차는 **스킵**, 다음 회차는 예정 시각에 정상 시도 (재시도 없음)
- **매도 주문 실패 시** 시그널 유형별 재시도 정책:
  - **손절 / 취소 시 매도**: 한 번 발동하면 체결 완료까지 **5초 간격 무제한 재시도** (가격 회복과 무관)
  - **본전 매도**: 현재가 ≤ 매수가 조건이 유지되는 동안 재시도. 가격이 매수가 위로 회복되면 재시도 중단 (조건 재충족 시 재발동)
  - **추세 꺾임**: 해당 3분봉에서 조건이 유지되는 동안 재시도. 다음 봉에서 조건 해소 시 중단 (이후 재충족 시 재발동)
  - **장 마감 강제 청산 / 목표 익절 분할 매도**: 해당 시그널 해소 없이 체결 완료까지 무제한 재시도
  - 거래정지가 길어져 장 마감까지 청산 못 한 경우 — 미청산 종목으로 리포트에 표시 + 사용자에게 알림. 다음 영업일 처리는 사용자가 수동으로 결정
- **주문 타임아웃 시**: 재시도 전 KIS 체결 내역 조회로 실제 체결 여부 먼저 확인 후 결정 (중복 주문 방지)
- 주문 실패는 모두 로그로 기록

## 주요 산식 및 기준

### 추세 꺾임 판단

```
3분봉 기준: 0봉(현재봉)의 현재가 < 1전봉의 시가
```

- 조건: 매수가 대비 **+5% 이상 상승 후** 위 조건 충족 시 추세 꺾임으로 판단
- **3분봉 고정** — 사용자가 설정하는 "추가 매수 간격"과 무관 (분할 매수 타이밍과 정점 감지는 별개의 시간 축)
- KIS API의 3분봉 응답을 그대로 사용
- **데이터 부족 처리**: 1전봉이 존재하지 않는 경우(장 시작 후 첫 3분) 추세 꺾임 판정 보류 — 상한가 도달 또는 이후 봉에서 조건 충족 시까지 잔여 수량 보유

### 매수가 산정 (증권사 기준)

```
매수가 = Σ((매수가격 × 매수수량) + 수수료 + 세금) / 총 매수수량
```

가중평균 방식, 증권사 제공 값 사용

## 화면 구성

### 매매 명령 화면

- 종목명 입력 (종목명 검색 기능 포함)
- 1회 매수 금액 입력 (원 단위)
- 매수 명령 전송 / 취소 버튼

### 실적 조회 화면

| 항목 | 설명 |
|------|------|
| 일자 | 매매 일자 |
| 종목명 | 매매 종목 |
| 매수금액 | 총 매수 금액 |
| 매도금액 | 총 매도 금액 |
| 수수료 | 거래 수수료 |
| 세금 | 거래세 |
| 수익금 | 순 수익 금액 |
| 수익률 | 수익 퍼센트 |

> **개발 우선순위**: 일별 실적 우선 개발, 월별 실적은 트레이딩 성과에 따라 추후 개발

> **데이터 저장소**: SQLite. 거래 내역 및 명령 상태를 로컬 파일로 영속화
